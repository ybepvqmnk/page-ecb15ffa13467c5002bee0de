02 / 使用说明

从下单到日常使用，五步

下面是不依赖任何具体客户端品牌的通用流程。每一步只描述你要完成的事，不描述你应当获得的体验。

  1. 先核对档位

    回到上方方案列表，按你的月度流量需求与同时在线设备数选档。设备数按「同时在线」计算，不是按装机次数计算。

  2. 确认计费周期

    月付按月续，年付一次付清并折算为十个月的价格。周期在订购页选定，两侧价格以本页展示为准。

  3. 取得配置信息

    完成订购后，你会获得用于配置客户端的账号信息。请把它当作密码管理，不随意转发给不在你设备清单内的人。

  4. 在设备上完成配置

    按下方客户端说明选择与你系统对应的入口，导入配置后逐台确认连通情况。设备数量上限按档位执行。

  5. 按需查看用量与更档

    流量按月重置。若发现月度额度长期吃紧或同时在线设备数不够，再考虑升档，不必一开始就买到最高档。

03 / 客户端

先确认系统，再选入口

Mysterious 不自建客户端。下列为按系统分类的入口说明；具体下载渠道与版本，请以你订购后收到的说明为准，本页不提供外部下载地址。

Windows

桌面端

用于台式机与笔记本。配置后请在设置中确认开机自启与系统代理两项是否为你想要的默认行为。

macOS

桌面端

安装后首次启动需在系统设置中允许其网络权限，否则配置导入成功也不会生效。

Android

移动端

移动网络与 Wi-Fi 下需分别验证一次连通性，部分系统会在省电模式下限制后台连接。

iOS / iPadOS

移动端

通过系统网络扩展方式工作。切换 App Store 账号前，请先确认已安装版本仍在可用状态。

Linux

命令行

适合在服务器或长期在线的设备上使用。建议以服务方式运行，并单独管理配置文件权限。

Router

路由器

用于整网设备统一接入。团队版的定制路由需求需通过客户经理沟通，普通档位不包含该项。

04 / 条款要点

下单前请先读这四条

这几条不是营销文案，是用来减少后续沟通成本的说明。

流量与设备

流量按自然月重置，未用完的额度不结转到下月。设备上限按同时在线数计算，超出上限时新设备将无法连接。

年付与月付在流量与设备权益上完全一致，差别只在计费周期与折算价格。

服务边界

本页未列出的性能数值、节点数量、线路覆盖率与可用性指标，均不构成承诺。流媒体解锁能力受平台策略变化影响，可能随时调整。

若所在地区对相关服务有明确限制，请自行确认合规性后再决定是否订购。

05 / 常见问题

常见问题，按编号逐条回答

以下问题的答案与页面上方的方案列表一致。若两者出现不一致，以方案列表为准，并请通过工单告知我们修订。

  1. 年付比月付省多少？怎么算的？

    年付价格按月付价×10 折算：基础版 ¥150、旗舰版 ¥350、团队版 ¥850。也就是说，按年付相当于为十二个月支付十个月的费用，具体金额已写在各自方案的价格行内。

  2. 三档之间最关键的差别是什么？

    两个可量化的差别是月度流量与同时在线设备数，分别是 100GB/3 台、300GB/5 台、1000GB/20 台。其余差别在权益层面：旗舰版起包含全节点原生流媒体解锁与 IPLC 专线游戏加速优化，团队版另含 VIP 专属高带宽节点、企业定制路由与专属客户经理。

  3. 中途想升档，原来的流量怎么处理？

    升档后按新档位的月度额度执行，设备上限同步调整。已使用的流量不追溯退回，也不额外扣费。降档同理，从新周期起按低档额度执行，建议在月度重置前后操作以减少浪费。

  4. 设备上限里的「同时在线」怎么理解？

    指同一时间保持连接状态的设备数量。关闭客户端或被系统挂起的设备不计入。若你在手机与电脑间频繁切换，通常不需要按设备总数购买更高档位；但若多台设备需要长时间保持连接，请按实际在线台数选档。

  5. 客户端由 Mysterious 提供吗？

    不是。我们提供配置信息与按系统划分的接入说明，客户端由各平台上的第三方软件承担。本页不提供下载地址，也不会要求你从非官方渠道安装额外组件。

  6. 团队版的定制路由需要准备什么？

    需要说明你的网络环境、需要统一接入的设备规模，以及是否存在特定的走向要求。这些信息由专属客户经理对接确认。定制路由属于团队版权益，基础版与旗舰版不包含该项。

  7. 流媒体解锁为什么可能变化？

    解锁能力取决于平台自身的识别与调整策略，不由我们单方面决定。我们会在能力发生变化时更新说明，但不承诺某个具体平台在任意时刻都可用。基础版为「基础流媒体解锁」，与旗舰版起的「全节点原生流媒体解锁」不是同一范围。
